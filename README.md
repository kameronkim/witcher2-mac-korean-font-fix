# The Witcher 2 Mac 버전 한국어 폰트 버그 수정

Steam Mac판 The Witcher 2에서 한국어 폰트가 보이지 않는 버그를 해결하는 패치입니다.

## 사용 방법

1. 저장소의 ZIP 파일을 내려받아 압축을 풉니다.
2. `Witcher2KoreanFontBugFix.command`를 더블클릭합니다.
3. `1. 패치 설치/업데이트`를 선택합니다.
4. 표시된 게임 경로를 확인하고 `y`를 입력합니다.
5. 설치 후 게임을 실행해 한국어 메뉴와 자막을 확인합니다.

패처는 Steam 설치 경로를 자동으로 찾습니다. 찾지 못하면 게임 폴더를 Terminal 창으로 드래그하세요.

## 변경하는 파일

- `CookedPC/globals/gui/fonts.swf`
- `CookedPC/globals/gui/fonts/fonts.csv`

설치/업데이트는 위 두 파일을 덮어씁니다. 제거는 위 두 파일을 삭제합니다.

## 한국어 설정

Steam에서 게임 언어를 한국어로 설정하세요. 상태 확인에서 `Language=KR` 경고가 나오면 한국어로 변경한 뒤 게임을 다시 시작하세요.

## macOS가 실행을 차단할 때

시스템 설정 > 개인정보 보호 및 보안에서 차단된 `.command` 파일의 **확인 없이 열기**를 선택한 뒤 다시 실행하세요.

## 제거 및 복구

메뉴에서 `2. 패치 제거`를 선택합니다. 원래 설치 상태로 되돌리거나 오류가 계속되면 Steam에서 설치 파일 무결성 검사를 실행하세요.
